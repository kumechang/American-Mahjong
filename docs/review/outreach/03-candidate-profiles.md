# レビュアー候補の人物像（具体例）

実在の人物ではなく、「こういう人を探す」という理想像の例です。探すときの検索語、面接（やり取り）で聞くこと、避けたい兆候を含めています。報酬は目安で、相場は募集して確認してください。

---

## A. ドメイン経験者（American Mahjong）

### 共通して必要な条件
- アメリカ在住で、American Mahjong（NMJL カード）を3年以上、定期的にプレーしている
- 今年のカードを持っている（毎年買い替えている）
- 初心者に教えた経験がある（または、初心者を受け入れる会を運営している）
- 英語でコメントを書ける（短い箇条書きで十分）
- **避けたい**: 中国式・リーチ麻雀の経験しかない人、上手いが教えたことがない人、掲載中のビジネスのオーナー本人（偏りが出るため。関係があれば申告してもらう）

### 例1: 地域の講師（最有力）
- **経歴**: 60歳前後の元小学校教師（または看護師）。10年前に友人に習い、7年前からコミュニティセンターや JCC で初心者向け講座を担当。今は年に4〜6回の入門講座を開き、のべ200人以上に教えた。
- **スキル**: ルールを噛み砕いて説明できる。初心者のつまずき（ジョーカーの扱い、Charleston の方向、鳴きの優先）を熟知している。カードの毎年の変更にも詳しい。
- **強み**: 「初心者に分かりやすいか」を判断できる。用語の言い換えを提案できる。
- **弱点**: 自分の会のローカルルールを一般化しがち → 「グループによって違う」と書いてもらう。
- **探し方**: 「American Mahjong lessons [city]」、MahJongg Maven の講師一覧、JCC・図書館・シニアセンターの講座の講師。当サイトに載っている講師も対象（ただし関係を申告してもらう）。
- **報酬の目安**: 90分〜2時間で、150〜300ドル程度、またはそれ相当のギフトカード。

### 例2: クラブ運営者・大会経験者
- **経歴**: 50代のクラブ主宰。10年以上プレーし、週2回のオープンプレーを主催。地域の大会の運営やスコア管理の経験がある。
- **スキル**: 支払い（自摸・ジョーカーなしの倍）、死に手、流局、鳴きの優先などの細かい規則に強い。
- **強み**: 例外的なルールと、実際に起きるトラブルを知っている。
- **弱点**: 初心者向けの言葉遣いには無頓着なことがある → 英語編集者と合わせて見る。
- **探し方**: 地域の American Mahjong の Facebook グループの管理者、リーグや大会の主催者。
- **報酬の目安**: 例1と同程度。

### 例3: 長年のプレーヤー兼アドバイザー
- **経歴**: 70歳前後。40年以上のプレー歴があり、複数の年のカードを見てきた。教えたことは少ないが、多くのグループでプレーした。
- **スキル**: 歴史・マナー・習慣に詳しい（Etiquette のレビューに最適）。
- **強み**: 「グループによる違い」を広く知っている。
- **弱点**: 専門用語を初心者に説明する経験が少ない。
- **探し方**: 知人の紹介、教会・シナゴーグ・コミュニティのサークル。
- **報酬の目安**: 謝礼（ギフトカード）と、感謝の一言で足りることが多い。

### 見極めの質問（メールまたは短い通話で）
1. How many jokers are in a set, and how many tiles in total?
2. How many tiles does each player hold at the start? Does the dealer differ?
3. In which directions do you pass in the first and second Charleston? Can jokers be passed?
4. Can a joker be used in a single or a pair?
5. What do you tell a brand-new player who is afraid of making a mistake?
6. Are there rules where groups you've played with differ? Give an example.

（1〜4は答えが決まっているので、その正確さを見ます: 152枚 / ジョーカー8枚 / 13枚・親は14枚 / 右→前→左、次に左→前→右 / ジョーカーは渡せない / 単独・ペアには使えない）

### 兆候
- **良い**: 「自分のグループでは〜だが、他では〜のことも」と言える。分からないことを分からないと言える。
- **要注意**: すべてを断定する。他の麻雀の用語（リーチ、ドラ）が混ざる。カードを持っていない。

## B. 英語編集者（US English）

### 共通して必要な条件
- 母語が米国英語で、米国在住（または米国の出版・Web 経験が長い）
- 一般消費者向けの Web やアプリの文章の編集経験（2〜3年以上）
- 平易な英語（中学生レベル）で、40〜80歳の読者に書く経験
- スタイルガイド（AP または Chicago）に慣れている
- **避けたい**: 自分の文体に全部書き直す人、AI の出力をそのまま返す人、マーケティングの誇張を好む人

### 例1: 消費者向け Web の編集者・校閲者（最有力）
- **経歴**: 40代のフリーランス編集者。10年間、ライフスタイル系メディアと通販サイトで編集・校閲を担当。ヘルプ記事や FAQ の編集も多い。
- **スキル**: AP スタイル、読みやすさの指標（Flesch-Kincaid）、トーンの統一、用語表の作成、SEO を意識したタイトルと説明文。
- **強み**: 「同じ型の文が並ぶ」問題を、構造の代案で示せる。
- **弱点**: マージャン用語を知らない → ドメイン経験者と一緒に確認する。
- **探し方**: Reedsy、EFA（Editorial Freelancers Association）、ACES のコミュニティ、「plain language editor」「consumer web copy editor」で検索。
- **報酬の目安**: 7,000語で 200〜500ドルの固定額が一つの目安。サンプル（600語）を先に有償で頼む。

### 例2: 元新聞記者・地方紙の編集者
- **経歴**: 60代。地方紙で30年、見出しと本文の編集を担当。地域の団体やイベントの記事に強い。
- **スキル**: 簡潔で自然な文、事実と意見の区別、断定的な表現を避ける書き方。
- **強み**: 「保証に聞こえる表現」の指摘が的確。地域の紹介文に向いている。
- **弱点**: 硬い文体に寄りやすい → 温かさは声のガイドで補正する。
- **探し方**: 元記者の会、地域の大学の広報・ジャーナリズム学科、ライターズグループ。
- **報酬の目安**: 例1と同程度、または時間単価で確認。

### 例3: 平易な英語（plain language）の専門家
- **経歴**: 30〜40代。高齢者向けの保健・行政サービスの資料を、平易な英語に直してきた。
- **スキル**: 読みやすさの評価、アクセシビリティ、専門用語の言い換え。
- **強み**: 40〜80歳の読者に合う文章に整えられる。
- **弱点**: 個性や温かさが薄くなることがある → 声のガイドで維持する。
- **探し方**: 「plain language specialist」「health literacy editor」、政府機関の外注ライター経験者。
- **報酬の目安**: 例1と同程度。

### 見極め方（サンプル課題・有償・約30分）
次の課題を送り、直した文とコメントを見ます。
1. `Charleston` と `Scoring` の2ガイド（約600語）を編集してもらう。
2. 都市の紹介文を5本渡し、似た型を避けた書き直し案を2種類つくってもらう。
3. 「American Mahjong」「Mah Jongg」「NMJL」の使い分けについて、推奨と理由を書いてもらう。

### 見るポイント
- 指摘に理由がある（「なぜ不自然か」を短く説明している）
- 元の温かい声を残したまま直している
- 断定的な表現を穏やかにする案が出る
- 分からないマージャンの規則を「要確認」と書き、推測で直していない

### 兆候
- **良い**: 直す前に質問をする。変更箇所を分かるように示す。書き直しは必要な範囲にとどめる。
- **要注意**: ほぼ全文を書き直す。理由を書かない。AI ツールで機械的に置き換えたように見える。

## C.（参考）弁護士

- **経歴**: 米国の弁護士（ウェブサイトのプライバシー・利用規約・広告開示の実務経験）。個人情報保護法（州法）、FTC の広告開示指針に詳しい。
- **探し方**: 州の弁護士会の紹介サービス、スタートアップ向けの定額法務サービス。
- **依頼の範囲**: `/privacy`、`/terms`、`docs/LEGAL_AND_PRIVACY.md`。広告やアフィリエイトを始める前に。定額で依頼。
